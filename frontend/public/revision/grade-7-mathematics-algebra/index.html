Grade 7 Mathematics: Algebra Revision Questions

A letter can stand for a number. Practise turning everyday situations into expressions, collecting like terms and solving simple equations, one step at a time.

Before you start

  • Only collect like terms: 2x + 3x = 5x, but 2x + 3 cannot be combined.
  • When substituting, replace the letter with its value before calculating.
  • Keep an equation balanced by doing the same operation to both sides.

Answers and explanations

Open a question to see the answer and the steps behind it.

1. Simplify 3x + 2x.

Answer: 5x. Both terms contain x. Add their coefficients: (3 + 2)x = 5x.

2. Find 2a + 3 when a = 4.

Answer: 11. Substitute a = 4: 2 × 4 + 3 = 8 + 3 = 11. Multiply before adding.

3. Solve x + 7 = 15.

Answer: 8. Subtract 7 from both sides: x = 15 − 7 = 8. Check: 8 + 7 = 15.

4. One exercise book costs b shillings. Which expression gives the cost of four books?

Answer: 4b. Four books cost b + b + b + b = 4b shillings. Multiplication represents four equal costs.

5. Solve 3y = 18.

Answer: 6. Divide both sides by 3: y = 18 ÷ 3 = 6. Check: 3 × 6 = 18.
