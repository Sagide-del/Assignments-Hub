# Homepage product screenshots

These images are captures of the real Assignment Hub frontend using illustrative records, converted to WebP for public-page delivery. They are static screenshots, not live simulations or user activity statistics. The homepage starts with the respiratory simulator and offers assignments, skills and dashboard views. Source captures are in `marketing/2026-challenge/source/`.

The homepage crops screenshots with CSS to focus on the workspace and offers an enlarged full screenshot. Crop coordinates in `src/components/HomeProductPreview.tsx` refer to the original pixel dimensions; update those when replacing a screenshot. Keep sample records free of personal information. No protected API calls or AI generation requests are needed to display the gallery.
