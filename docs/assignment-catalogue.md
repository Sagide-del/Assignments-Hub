# Subject and topic assignment catalogue

My Assignments now opens a subject-card library. Opening a subject shows topic cards; opening a topic shows only its assignments with their existing Start, Continue, View submission or Review answers action. Breadcrumbs, browser history and URL parameters preserve the selected subject/topic, search, status and sort. Opening an exam carries a validated return location so its Back action returns to that topic.

Subject/topic cards use actual visible assignments and the current learner's submission states. Their progress label is **submitted**, not mastery or an invented completion score. Unreleased scores remain hidden. Search covers subject names, topic labels and assignment titles; status filters work at every level, and assignment sorting is available within a topic. Errors are distinguished from genuine empty folders. Browsing does not start assessments or create enrollments; the existing presence heartbeat remains active.

The backend does not currently have a first-class Assignment topic column. The grouping helper accepts optional topic metadata, then a plain `Topic: The Mole` line in an existing description, then a conservative cleanup of the assignment title. For example, `The Mole - Quiz 1` and `The Mole - Quiz 2` share a topic; `Revision Gas Laws` becomes Gas Laws. Generic titles use General practice. Different subject folders never share assignment objects. Common Mathematics spelling variants are unified for navigation. Assignment titles and stored records are not rewritten, and these folders do not claim verified KICD strand/sub-strand classification. Staff can label a topic in the existing description without changing a paper's title. No schema migration or new endpoint is required.

Supplementary LearningDesignPanel/guide-link UI was removed from assignment pages, released assignment review, skills pages/lessons and STEM pages/players. Actual lesson teaching, teacher instructions, first-aid illustrations, labs, marking and exam autosave remain. The dedicated My Resources guide and previous reflection data are retained.

Validation: 43 frontend checks, including six new catalogue grouping/search tests, and a local Playwright flow covering subject/topic/paper drill-down, multiple papers per topic, return-location context, refresh/history, searching, status filters, unreleased-score privacy, error/retry, empty data and widths 320/390/768/1024px. The fixture does not change real learner data.
