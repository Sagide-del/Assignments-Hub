# Illustrated recall cards

The recall-card face is picture-led: Assignment Hub’s official logo, charcoal/lime/white branding, short title, a dominant illustration, essential labels and a compact supporting pictogram rail. It omits prose, memory-aid paragraphs and fact lists. Heart cards pair the cutaway with the circulation sequence; plant cells use function pictograms; lungs show the airway sequence; circuits use component/loop cues. Student notes remain saved in the existing JSON and appear only in an optional Study notes disclosure outside the card. Practice questions are a separate disclosure. The numbered view hides labels; reveal restores the labels without adding prose to the card. Existing PDF resources remain accessible.

Illustrations are generated from bounded JSON metadata in the existing `MnemonicCard.content` field. There is no schema migration, manual asset upload or additional image-provider request per generated card. Both curriculum-outcome and source-based generation ask for that metadata in their existing AI request. The server validates and retains only supported visual properties; arbitrary SVG, HTML and remote image URLs are not accepted as visual payloads.

Available visuals are an authored-template diagram (heart, lungs, plant cell, closed electrical circuit), labelled concept map, ordered process, comparison, timeline or validated proper-fraction model. The heart, lungs, plant-cell and circuit-kit artwork is stored in `frontend/public/recall-illustrations/`. These are original generated textbook-style assets, inspected before inclusion; the circuit image was corrected so the closed switch and both lamp-terminal connections form a visible loop. `recall-diagrams.ts` defines the authored label positions and captions. Scientific diagrams use fixed authored callouts rather than model-invented coordinates. Anatomy is illustrative, not to scale. The enlarged image viewer provides a native keyboard-accessible dialog, including Escape to close. All generated content and choice of diagram still need editorial accuracy review. A small diagram library is not a claim of a bespoke anatomical illustration for every possible curriculum outcome.

Older text cards remain stored unchanged. The frontend uses narrowly matched science-topic diagrams where applicable, and otherwise builds a concept map from the card's existing facts. It does not substitute an unrelated anatomy image for an English literary reference to the heart. Admin review uses the same study-card component and supports changing the visual style, diagram, caption and labels before saving an unpublished draft. Old content does not need paid regeneration just to use the new presentation.

Print / Save PDF clones only the revealed visual card (excluding the cue, study notes and practice questions) into an isolated print document, loads its styles and illustration, and invokes the browser print dialog. It excludes surrounding navigation and other learner content. Print CSS uses landscape A4; long legacy content can require additional paper. Local review buttons suggest intervals but do not claim a persisted spaced-repetition schedule or measured mastery.

Checks: backend recall validation and card-service tests; frontend `npm run test:recall`; browser coverage for legacy cards, answer reveal, deck navigation, PDF resources, isolated printing, admin metadata editing and mobile widths. The content API advertises `illustratedRecallCardsVersion: 1`; frontend deployment waits for that capability so visual metadata is not silently dropped by an older backend validator.


The white-paper masthead gives the official logo clear space and links to `https://assignmenthub.co.ke/`. The footer has the same visible, clickable website address; the browser's PDF export preserves both hyperlinks. A small Recall club sticker and memory-mission cue add a playful touch using the brand palette. The optional 30-second challenge covers the study notes, counts down using elapsed wall-clock time and cleans up its timer when the card changes. Revealing the notes stops the challenge. It does not score learners, save a completion record or imply measured mastery. Interactive zoom/challenge controls are excluded from the printed sheet. Artwork is shared across stored cards and does not trigger generation when learners view it.


In picture mode, process/timeline cards use connected visual stages, comparisons use labelled panels, fractions use shaded equal parts and concept maps use connected nodes. Full diagram details remain available in Study notes and are not deleted. Future generation prompts ask for 1–4-word visual labels. No regeneration is required for stored cards to use the picture-led presentation.
